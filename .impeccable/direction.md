# Configuration surface

THESIS: Trace global configuration from harness availability to its actual source without changing where the user stores it.

OWN-WORLD: A minimal file configuration utility. White canvas, dark text, and gray tones. System sans-serif for controls and monospaced paths. Thin rules and compact headings. States are explicit text; uncertain and broken states use weight and underline. No editorial styling, decorative marks, or promotional copy. User explicitly requested this palette and appearance, superseding the initial colored direction.

STORY: Choose a category, compare Codex and Pi, search and filter, inspect the physical source and harness paths, and read source content. No editing or change actions.

FIRST VIEWPORT: Left navigation, compact workspace heading, a real inventory table, and a right source inspector. At narrow sizes navigation becomes horizontal and the inspector becomes a dismissible overlay. Differences are intentional; uncertainty is labeled.

FORM: Comparison table and source inspector were explicitly proposed and approved by the user before building. Concept seed b0489854 ran; the user's pinned structure takes precedence over the assigned direction. Plain TypeScript and code-led implementation follow the approved smallest-solution brief. No approved comp or raster assets. Large-type marketing surfaces and decorative artifacts would conflict with this operating tool.
